GUARDS ADDED / CHANGED (matvec_multiply.py)
-------------------------------------------
1. New helper _is_number(value): returns True for int or float but not bool.
   dot_product uses it, so booleans are rejected.
2. dot_product checks vector_a and vector_b elements separately and raises
   TypeError naming the argument and index, e.g.
   "vector_b element at index 1 must be an int or float."
3. matrix_vector_product uses enumerate() over the rows so that its messages
   include the row index:
     - "Matrix row 1 must be a list."
     - "Matrix row 1 has length 3, but the vector has length 2."
     - A TypeError from dot_product is re-raised (chained with "from err")
       as "Matrix row N and the vector must contain only int or float
       values (...)", which replaces the misleading "Vector elements must be
       numeric."
4. Added a comment stating that NaN and infinity propagate according to
   normal Python floating-point arithmetic and are not treated as invalid.
   This follows my decision not to restrict them, because they are valid
   Python floats and the assignment does not require rejecting them.
Unchanged: the list-only input contract, the empty-input checks, the
indexed for-loop accumulation, and main().
